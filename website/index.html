C++, Python, and Java write the same authenticated formats

BaseFWX

BaseFWX encrypts payloads with AES-256-GCM and derives keys with Argon2id or PBKDF2. An optional master path also wraps the content key with ML-KEM. The C++, Python, and Java runtimes read and write the same fwxAES, b512, and pb512 containers. This portal carries the release trail: binaries, detached signatures, checksums, and scan reports.

Verify a download

Two independent checks. The signature proves who built the file, the checksum proves it arrived intact.

Detached signatures

Published for every binary in the release.

Verify
gpg --verify basefwx-linux-amd64.sig basefwx-linux-amd64

SHA-256 checksums

Every asset ships a sidecar. MD5 stays on the hash page for file identification, not for security.

Check
sha256sum -c basefwx-linux-amd64.sha256

Reading a report

Engines disagree, and a binary that few people have downloaded yet often draws heuristic flags on its own.

Check that the SHA-256 shown on the report matches the value on the checksum page first. If it does not match, the report describes a different file.
