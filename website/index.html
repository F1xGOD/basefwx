Maintained containers / three runtimes

BaseFWX Authenticated containers across C++, Python, and Java

BaseFWX encrypts payloads with AES-256-GCM. Keys come from Argon2id or PBKDF2; the optional master path wraps the content key with ML-KEM. C++, Python, and Java share the portable fwxAES, b512, and pb512 variants; the compatibility reference records the C++ stream and Java packing exceptions. This portal holds the binaries, signatures, hashes, and scan reports.

Verify a download

Two independent checks. The signature proves who built the file, the checksum proves it arrived intact.

Detached signatures

Published for every binary in the release.

Verify
gpg --verify basefwx-linux-amd64.sig basefwx-linux-amd64

SHA-256 checksums

Every asset ships a sidecar. MD5 stays on the hash page for file identification, not for security.

Check
sha256sum -c basefwx-linux-amd64.sha256

Reading a report

Engines disagree, and a binary that few people have downloaded yet often draws heuristic flags on its own.

For direct binaries and the Java archive, compare the report SHA-256 with the checksum page. A Windows report covers the inner executable, so verify its release ZIP separately with the ZIP checksum.
