BaseFWX

BaseFWX wraps keys with ML-KEM and encrypts payloads with AES-256-GCM. Its C++, Python, and Java runtimes share the fwxAES, b512, and pb512 formats. This portal publishes the release trail needed to download, inspect, and verify each artifact.

Integrity and verification

Verify every download with hashes and detached signatures.

GPG signatures

Detached signatures are published for every binary.

Verify
gpg --verify basefwx-linux-amd64.sig basefwx-linux-amd64

SHA-256 checksums

Release assets include SHA-256 checksums. MD5 values remain on the hash page for file identification, not security verification.

Check
sha256sum -c basefwx-linux-amd64.sha256
